# 🕒 Relógio Digital no Terminal

Um projeto simples em **Python** que exibe um relógio digital em tempo real no terminal.

## ⚙️ Funcionalidades
- Mostra **hora e data atualizadas a cada segundo**
- Atualização em tempo real  
- Interface simples e limpa no terminal  

## 🚀 Como executar
```bash
git clone https://github.com/seuusuario/digital_clock.git
cd digital_clock
python clock.py
